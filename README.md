# AgroSense - AI Based Crop Recommendation System 🌱

AgroSense is an AI-powered crop recommendation system that helps farmers and users identify the most suitable crop based on soil nutrients and environmental conditions using Machine Learning techniques.

## 🚀 Live Demo

https://crop-recommendation-system-new.onrender.com/

## 🚀 Features

* Crop recommendation using Machine Learning
* Fertilizer recommendation system
* Soil and environmental parameter analysis
* Web-based user interface
* Real-time prediction system
* Trained ML models for accurate recommendations

## 🧠 Machine Learning Models

* Random Forest
* Gradient Boosting
* Logistic Regression

## 📊 Input Parameters

* Nitrogen (N)
* Phosphorus (P)
* Potassium (K)
* Temperature
* Humidity
* pH
* Rainfall
* Soil Type

## 🛠️ Tech Stack

* Python
* Flask
* Scikit-learn
* Pandas
* NumPy
* HTML/CSS
* Machine Learning
